# Fast reactor open literature

Open literature for this repository, kept in the same way as
`reactor-literature/theodore-open-corpus/` in
[outram-park-backend](https://github.com/theodoreOnzGit/outram-park-backend).
**This repository is public**, so every document here must be
redistributable, on a ground stated by the document itself or by its
publisher. Where a document is hosted does not count.

Proprietary literature (no verified redistribution basis) never goes here: it
goes to the private repository `propreitrary-literature-theodore`. Notes,
citations and connections *about* a proprietary document may live here; the
document and its extracted full text may not.

Grounds used so far:

1. **Open access under a Creative Commons Attribution licence (CC BY)**, in
   `cc-by/`.
